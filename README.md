# Vehicle-Rental-Management-System

## About the Project

Vehicle Rental Management System is a simple Python console-based project.

The main purpose of this project is to calculate the rental cost of a vehicle based on the vehicle selected and the number of rental days.

The project is made using basic Python concepts, so it is easy to understand and run.

## Features

The project currently provides the following options:

1. Show Vehicles
2. Rent Vehicle
3. Exit

The system contains three sample vehicles:

| Vehicle Type | Vehicle | Price Per Day |
| ------------ | ------- | ------------: |
| Car          | Swift   |         ₹1000 |
| Bike         | Activa  |          ₹500 |
| Car          | Nexon   |         ₹1200 |

## How It Works

When the program starts, it displays a menu.

The user can select an option:

### 1. Show Vehicles

This option displays the available vehicles along with their type and price per day.

### 2. Rent Vehicle

The user selects a vehicle and enters the number of days.

The program calculates the total rental cost using:

```text
Total Rent = Price Per Day × Number of Days
```

For example:

```text
Swift = ₹1000 per day
Days = 3

Total Rent = ₹1000 × 3
           = ₹3000
```

### 3. Exit

This option closes the program.
